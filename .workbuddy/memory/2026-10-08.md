## 信息流支持混合内容（视频 / 直播 / 图片）

需求：模型返回的数据可能不全是视频，也可能是直播或一张宣传图，同一信息流要混合渲染。

- 新增 `lib/models/feed_item.dart`：`FeedItemType`（video/live/image）枚举 + `FeedItem` 统一模型（url/coverUrl/imageUrl/title/actionUrl/viewerCount/type 等），`fromJson` 按 `type` 字段解析（缺省按 video），`copyWith`/`==`/`hashCode`，`formatCount` 与 `posterUrl`/`mediaUrl` 辅助。`video_model.dart` 已删除。
- 播放器池 `video_player_pool.dart`：新增 `live` 标识（`entryFor(url, live:)` 与 `VideoPlayerEntry.live`），`replay()` 在直播时只 `play()` 不 `seekTo(0)`；直播流不支持 seek。
- `short_video_item.dart`：参数由 `VideoModel` 改为 `FeedItem`；直播隐藏进度条、底部信息区显示「直播中」标 + 在线人数；封面改用 `posterUrl`。
- 新增 `lib/widgets/image_feed_item.dart`：全屏图片渲染，含右侧互动栏（复用 `VideoSideActions`）、底部文案 + 「查看详情」CTA（actionUrl）、双击点赞；无播放器/进度条。
- `video_side_actions.dart`：参数 `VideoModel video` → `FeedItem item`。
- `feed_tab_view.dart`：`_items/initialItems` 改为 `List<FeedItem>`；`itemBuilder` 按 `item.isImage` 分派 `ImageFeedItem` / `ShortVideoItem`（直播传 `live:true`）；`_syncPlayback` 对图片跳过播放窗口、对直播只 `play`。
- 收藏链路同步：`favorites_feed_page.dart` initialItems 改 `List<FeedItem>`；`favorites_list_page.dart`/`personal_center_page.dart` 改类型 + 缩略图改用 `posterUrl`。
- 仓库 `video_repository.dart`：`fetchFeed` 返回 `List<FeedItem>`；mock `_mockFeed` 增加 `type` 字段，含 3 条 HLS 直播（test-streams.mux.dev 公共测试流）与 3 张图片（picsum 宣传图 + actionUrl）。
- 单测 `test/feed_item_test.dart`（原 `video_model_test.dart` 删除）：覆盖 type 解析、缺省 video、posterUrl 优先级、计数格式化，5/5 通过。
- README 同步更新目录结构、字段表（含 type/live/image 字段）、接入真实接口代码示例。
- 验证：`dart analyze lib` 无告警、`dart test` 5/5 通过。`flutter analyze` 在本沙箱会卡死（与之前 `flutter build ios` 同类环境问题），改用 `dart analyze` 校验即可。

## 给每个 item 的点击事件加 logger

需求：每个 item 的点击/交互事件都要打日志。

- 新增 `lib/utils/logger.dart`：`Logger` 单例 + 顶层 `logEvent()`。默认 `sink` 用 `debugPrint` 打印 `[track] 事件名 {...}`，接入真实埋点时只替换 `Logger.instance.sink`，业务调用不变。
- 埋点覆盖：
  - `feed_tab_view.dart`：`feed_item_impression`（划到即曝光）、`like_toggle` / `like_double` / `follow_toggle`、`comment_click` / `share_click` / `image_detail_click`（在 itemBuilder 内统一包装转交上层回调）；新增 `_trackParams()` 公共参数（item_id/type/channel/index/page）。
  - `short_video_item.dart`：`play_toggle`（含 playing 状态）、`mute_toggle`、`desc_toggle`。
  - `image_feed_item.dart`：`desc_toggle`（查看详情走 feed_tab_view 的 onAction 包装，避免重复打点）。
  - `favorites_list_page.dart` / `personal_center_page.dart`：`favorite_open`（from 区分来源）、个人中心 `open_all_favorites`。
- 双重点赞只由 `_doubleTapLike` 打 `like_double`，widget 内不再打，避免重复。
- README 新增「埋点 / 日志」章节（含事件清单表）。
- 验证：`dart analyze lib` 无告警。

## 信息流整屏点击：直播进直播页、图片只埋点

需求：直播 cell 点击整个 item 进入直播界面；视频保持单击暂停/再点击播放；图片 cell 单击仅打 log 不跳页。

- 新增 `lib/pages/live_page.dart`：直播占位页，仅顶部返回按钮 + 基础展示（作者名、在线人数、封面占位），真实直播能力后续接入。
- `short_video_item.dart`：新增 `onOpenLive` 回调；`_handleTap` 在直播且 `onOpenLive!=null` 时整屏单击走导航（双击仍走点赞，timer 被 `_handleDoubleTap` 取消）；视频仍走 `_togglePlay`。
- `image_feed_item.dart`：新增 `onCellTap` 回调并接到手势层 `onTap`；整屏单击仅触发该回调，双击点赞不变。

- README 埋点表新增 `live_cell_click` / `image_cell_click`，并在「混合多形态」说明补整屏点击行为。
